NÃO HÁ MIGRATION.

POR QUE ESSA CAMADA EXISTE

A regra de negócio não deve depender diretamente do Asaas.

Hoje:
PaymentGatewayInterface
        ↓
AsaasGateway

Futuramente poderíamos ter:
PaymentGatewayInterface
        ├── AsaasGateway
        ├── StripeGateway
        └── outro provedor

Sem fazer o módulo Assinaturas depender do vocabulário interno
de um gateway específico.

CONFIGURAÇÃO

Adicione ao .env local:

ASAAS_ENV=sandbox
ASAAS_API_KEY=<SUA CHAVE DE SANDBOX>

ATENÇÃO AO $

As chaves atuais do Asaas possuem prefixo com "$".

Sandbox:
$aact_hmlg_

Produção:
$aact_prod_

O caractere "$" faz parte da chave.

O vlucas/phpdotenv lerá a variável do arquivo .env.
Não coloque a chave diretamente em string PHP.

SEGURANÇA IMPLEMENTADA

- API key somente em variável de ambiente;
- nunca enviada ao navegador;
- nunca gravada no banco;
- nunca exibida pelo CLI;
- nunca escrita em logs por esta camada;
- base URL limitada aos hosts oficiais do Asaas;
- redirects HTTP desabilitados;
- timeout de conexão;
- timeout total;
- validação de prefixo sandbox/production;
- resposta inválida é rejeitada;
- erros do gateway não são propagados integralmente.
